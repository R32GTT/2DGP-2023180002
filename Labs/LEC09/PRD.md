## 1. 제품 개요

`sonic-sprite.png`에 들어 있는 소닉 스프라이트 프레임을 동작별로 잘라 재생하는 단일 파일 데스크톱 프로그램이다. 사용자는 스프라이트 시트에 포함된 동작을 순서대로 볼 수 있으며, 별도의 게임 플레이나 설정 작업은 필요하지 않다.

각 동작은 5회 재생하고 1초간 쉰 뒤 다음 동작으로 넘어간다. 마지막 동작까지 재생하면 처음 동작부터 같은 순서로 무한 반복한다.

## 2. 목표 및 범위

### 목표

- `sonic-sprite.png`에 포함된 모든 소닉 동작을 프레임 애니메이션으로 재생한다.
- 각 동작을 지정된 프레임 순서로 정확히 5회 재생한다.
- 동작 사이에 1초 대기한 뒤 다음 동작을 재생한다.
- 마지막 동작 재생 후 첫 동작으로 돌아가 무한 반복한다.
- 화면에서 소닉 이미지가 잘 보이도록 충분히 확대하고, 잘리거나 찌그러지지 않게 표시한다.
- 개발 결과물을 `sonic_animation_viewer.py` 단일 Python 파일로 제공한다.

### 범위 제외

- 소닉 조작, 충돌, 물리, 스테이지 등 게임 기능
- 스프라이트 시트 편집기 또는 자동 동작 인식 기능
- 사용자가 임의의 이미지나 애니메이션 파일을 불러오는 기능
- 재생 속도 조절, 동작 선택 메뉴 등 별도 UI 기능
- 별도 JSON·설정 파일 또는 추가 Python 모듈

## 3. 사용자 시나리오

1. 사용자가 `Labs/LEC09/sonic_animation_viewer.py`를 실행한다.
2. 프로그램이 같은 디렉터리의 `sonic-sprite.png`를 불러온다.
3. 첫 동작을 자동 재생하고, 모든 동작을 요구된 횟수와 순서로 반복 재생한다.
4. 사용자는 창을 닫거나 `ESC` 키를 눌러 프로그램을 종료한다.

## 5. 애니메이션 데이터 요구사항

- 프레임 정의와 동작 목록은 단일 파일 안에 둔다. 별도 메타데이터 파일을 만들지 않는다.
- 각 동작은 이름과 순서가 있는 프레임 목록으로 표현한다.
- 프레임 목록에는 스프라이트 시트 기준의 `x`, `y`, `width`, `height`를 지정한다.
- 좌표는 이미지의 왼쪽 위 원점을 기준으로 기록하고, Pico2D의 좌표계에 필요한 변환은 한 곳에서 처리한다.
- 스프라이트 시트에 포함된 제목, 크레딧, 장식 요소는 동작 프레임에 포함하지 않는다. 소닉 동작에 해당하는 프레임만 등록한다.
- 이미지 확인 결과 `y=327..370` 행의 Tails 프레임(`x=31..59`)은 소닉 동작이 아니므로 재생 목록에서 제외한다.
- 각 프레임의 표시 시간은 조정 가능하게 둔다. 기준 시간이 별도로 정해지지 않은 경우 초기값은 프레임당 0.1초로 설정하고, 실제 재생 결과를 확인해 조정한다.

## 6. 화면 및 실행 요구사항

- 캔버스 크기는 1200×800으로 설정한다.
- 프레임 크기에 맞춰 확대율을 계산한다. 가장 큰 프레임도 캔버스 안에 들어오게 하고, 가능한 화면 영역을 충분히 활용한다.
- 가로세로 비율을 유지하며 이미지가 캔버스 경계에서 잘리지 않도록 한다.
- 실행 명령은 `Labs/LEC09` 디렉터리에서 `python sonic_animation_viewer.py`를 기준으로 한다.
- 필요한 실행 환경은 Python과 Pico2D다. 추가 외부 라이브러리는 도입하지 않는다.
- 실행 파일 위치를 기준으로 이미지 경로를 계산해 저장소 루트 등 다른 작업 디렉터리에서 실행해도 스프라이트를 찾을 수 있게 한다.

## 7. 인수 기준

1. `sonic_animation_viewer.py`가 Python과 Pico2D 환경에서 실행되고 `sonic-sprite.png`를 불러온다.
2. 프로그램에 등록된 모든 소닉 동작이 정확한 프레임 순서로 재생된다.
3. 각 동작은 전체 프레임 시퀀스를 정확히 5회 완료한 뒤 다음 동작으로 넘어간다.
4. 동작 전환 간격은 1초이며, 마지막 동작 뒤 첫 동작으로 돌아가 반복한다.
5. 캔버스 크기는 1200×800이며, 이미지가 충분히 확대되어 보이고 비율이 유지되며 화면 밖으로 잘리지 않는다.
6. 제목·크레딧 등 장식 영역이 소닉 애니메이션 프레임으로 재생되지 않는다.
7. `ESC`와 창 닫기 모두 정상 종료하며 캔버스가 정리된다.
8. 스프라이트 파일이 없거나 프레임 데이터가 잘못된 경우 문제를 알리는 메시지가 출력된다.
9. 애플리케이션 코드는 `sonic_animation_viewer.py` 한 파일에만 있으며, 스프라이트 PNG 외에 추가 실행 데이터 파일이 필요하지 않다.

## 9. 초기 구현 가정

- 스프라이트 시트에는 동작 태그나 프레임 메타데이터가 없으므로, 모든 동작과 프레임 좌표는 이미지 확인 후 코드 안에 직접 등록한다.
- 캔버스 크기 1200×800은 사용자가 지정한 요구사항이다.
- 프레임당 0.1초는 초기 재생값이며, 동작이 자연스럽게 보이도록 전체 프레임을 확인하면서 조정할 수 있다.
- “모든 동작”은 스프라이트 시트에서 확인되는 소닉의 애니메이션 프레임 시퀀스를 뜻한다. 단일 정지 이미지나 장식 텍스트는 별도 동작으로 취급하지 않는다.
